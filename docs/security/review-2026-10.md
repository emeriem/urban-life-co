# Security review — October 2026

## Controls included in the current security reconciliation

- Administrator access is loaded from the encrypted `ADMIN_EMAILS` AppDeploy secret, not from a source-code constant. Access fails closed if the secret is missing or empty.
- Contact submissions validate required fields and email format, cap field lengths, accept only known enquiry types, include a honeypot, and limit repeated submissions.
- Media listing is restricted to administrators and returns only the fields needed by the CMS.
- Image uploads allow only JPEG, PNG, WebP, and GIF.
- Update handlers prevent client-supplied identity and creation timestamps from overwriting stored record metadata.
- The service worker excludes API and cross-origin requests from its cache and bumps the cache version to purge older entries.

## Deployment prerequisite

Before deploying this backend, confirm that the encrypted `ADMIN_EMAILS` secret is configured in the target AppDeploy environment with the authorised administrator address or addresses, comma-separated. If the secret is missing, administrator access will be denied by design.
