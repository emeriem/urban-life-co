# Security review — October 2026

## Fixed in this change
| # | Finding | Severity | Fix |
|---|---------|----------|-----|
| 1 | Admin email hardcoded in `backend/index.ts` of a public repo | High | Allowlist now read from the `ADMIN_EMAILS` app secret (comma-separated). Fails closed if unset. |
| 2 | Service worker cached `/api/*` responses, including admin data and enquiries (PII), in browser storage | High | API and cross-origin requests are never cached. Cache bumped to `v3` so old entries are purged on activation. |
| 3 | `POST /api/messages` stored the raw request body (any fields, any size), no validation or throttling | Medium | Field whitelist, length caps, email validation, enquiry-type whitelist, honeypot, 3 per email per 10 minutes. |
| 4 | `GET /api/media` was public and exposed storage paths and internal ids | Medium | Admin only; explicit response fields. |
| 5 | Image upload accepted any `image/*`, including SVG (script-capable) | Medium | Allowlist: JPEG, PNG, WebP, GIF. |
| 6 | `PUT` handlers merged client bodies over records, allowing `id` / `createdAt` overwrite | Low | `id` and `createdAt` stripped from client input. |
| 7 | `ensureSeeds()` ran on every public request and could double-seed under concurrent first requests | Low | Runs once per instance. |
| 8 | Contact form had no data-use notice (Nigeria Data Protection Act 2023) | Compliance | Notice added under the form. A full privacy policy page is still needed. |

## Deployment order (important)
1. Create the `ADMIN_EMAILS` secret in AppDeploy first (comma-separated admin emails).
2. Then deploy. If the secret is missing, admin access is denied for everyone by design.

## Still open — needs a decision
- The old admin email remains in git history of the public repo. Treat it as exposed: enable 2-step verification or a passkey on that Google account, and consider a dedicated admin account.
- No privacy policy or terms page exists. Required once you collect names, emails and phone numbers.
- `backend/realtime-subscribers.ts` defines unauthenticated subscription routes. They are not mounted today; delete them or add auth before mounting.
- Rate limiting is best effort (database based). Put a CDN or WAF rule in front of `/api/messages` before any paid promotion.
- Admin dashboard counts cap at 100 records per collection.
- Google Photos import silently skips images over 750 KB; the admin only sees the imported count.
- Add a Content-Security-Policy header at the hosting layer.
